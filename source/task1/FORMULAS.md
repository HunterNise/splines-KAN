# Learned Density Formulas — KAN3 / KAN4 / KAN5

**Date:** 2026-05-20  
**Task:** Predict interior B-spline knot positions (degree 3, 6 knots, 2-D curves).

Each KAN architecture outputs a scalar **density score** $s$ per sliding window.
High $s$ → more probability mass in that region → soft-argmin places a knot there.
The formulas below describe what each trained network learned to compute.

---

## 0. Notation and Theoretical Target

### Variable convention

All features are computed from a window of $w$ consecutive curve points.

| Symbol | Meaning |
|--------|---------|
| $l_k$ | Chord length of the $k$-th edge in the window, normalised by the bounding-box diagonal of the full curve |
| $\theta_k$ | Signed turning angle at the $k$-th interior vertex (radians) |
| $\lvert\theta_k\rvert$ | Absolute turning angle (used from KAN5 onward) |
| $s$ | Density score output by Stage 1 (before softplus + normalise) |

Typical magnitudes for scale-normalised 2-D curves (100 points):
$l_k \approx 0.01$–$0.05$, $\lvert\theta_k\rvert \approx 0$–$0.8$ rad.

### Theoretical target

For a B-spline of degree $p$, the optimal knot distribution that minimises the
$L^2$ approximation error equidistributes the $p$-th root of the local curvature
(Burchard–Chalmers equidistribution theorem):

$$\boxed{s^*_i \;=\; \kappa_i^{\,1/(p+1)}, \qquad
\kappa_i \;\approx\; \frac{\lvert\theta_i\rvert}{l_{i-1}\,l_i}}$$

For degree 3 (cubic B-splines): $s^* \propto \kappa^{1/4}$, i.e. roughly the
**fourth root of discrete curvature**.  
Expanded: $s^* \propto \lvert\theta\rvert^{1/4} \cdot (l_0\,l_1)^{-1/4}$.

This is the benchmark against which each learned formula is judged.

## 1. KAN2 — Direct Global Regression

**Architecture:** `[200, 200, 100, 5]` full KAN on the flattened curve.  
**Best test loss:** 0.006773 (outputs-3)  
**Interpretability:** None.

The formula is a 200-variable linear combination of raw $(x, y)$ coordinates,
with large cancelling coefficients (typical range $\pm 5$). Because the inputs are
not rotation-invariant, the network implicitly encodes a global coordinate frame
and produces an entirely unstructured formula. No geometric insight can be extracted.

## 2. KAN3 — Sliding Window, Histogram Aggregation

**Architecture:** `[7, 16, 16, 1]` pure-addition KAN, window $w = 5$.  
**Inputs:** $[l_0, l_1, l_2, l_3,\ \theta_0, \theta_1, \theta_2]$ (7 intrinsic features).  
**Best test loss:** 0.011685 (outputs-2)  
**Interpretability:** Very low — pykan's symbolic regression produces multi-kilobyte
expressions involving nested exponentials, cosines, and $1/(1-\alpha x)^2$ poles:

```
# outputs-2 formula_full (abbreviated)
score = -0.043·exp(0.002/(0.049·exp(l_2) − 1 + 0.181/(1−0.34·θ_2)² + …)²)
      − 0.169/(−0.055·exp(l_1) − 0.065·exp(l_2) + 0.071·exp(l_3) + 1 + …)²
      + …   [~80 more terms]
```

The linear approximation (all edges fit with affine functions) is somewhat cleaner:

$$s_\text{linear}^{(\text{KAN3})} \;\approx\;
0.39\,l_0 - 1.10\,l_1 - 1.12\,l_2 - 0.13\,l_3 - 10.84\,\theta_0 + 0.32\,\theta_1 - 0.84\,\theta_2 - 0.07$$

The $\theta_0$ coefficient ($-10.84$) dominates and has the **wrong sign**:
negative turning angles produce higher scores. This is an artefact of the signed
angle convention — the network cannot distinguish $\theta_0 = +0.3$ (left turn)
from $\theta_0 = -0.3$ (right turn) as equally "sharp", because both should
increase density but have opposite sign in the linear formula.
The aggregation semantics in KAN3 were also inverted
(high score → wide interval → fewer knots), compounding the error.

**Verdict:** Despite 4,608 parameters and multiple non-linear layers, KAN3 learned
a nearly-random signed linear combination of chord lengths and angles with no
clear geometric meaning. The histogram aggregation and inverted semantics made
gradient-driven convergence to the curvature formula essentially impossible.

## 3. KAN4 — Sliding Window, Soft-Quantile Aggregation

**Architecture:** `[7, 5+1, 1]` KAN with one mult node, window $w = 5$.  
**Inputs:** $[l_0, l_1, l_2, l_3,\ \theta_0, \theta_1, \theta_2]$ (same 7 features).  
**Best test loss:** 0.016466 (outputs-1)

### 3.1 Best run — sparse formula (outputs-1)

$$\boxed{s^{(\text{KAN4})}_{\text{sparse}} \;\approx\;
6.49\,l_0 + 0.24\,(\theta_0 - 0.165)^2 + 0.045\,(\theta_1 + 1.10)^2 - 3.67}$$

The tiny terms at order $10^{-24}$ are numerical noise from pykan's symbolic fit
and are ignored.

**Interpretation:**
- **Chord length $l_0$** is the dominant term (coefficient 6.49): longer leading
  chord → higher density → more knots. Qualitatively correct — long chords imply
  under-sampled geometry.
- **Quadratic in $\theta_0$** (coefficient 0.24): score is raised whenever the
  first turning angle deviates from a small baseline ($0.165$ rad $\approx 9°$),
  whether turning left or right. This approximates $\lvert\theta_0\rvert$ via a
  quadratic — correct qualitative direction, wrong functional form.
- **Quadratic in $\theta_1$** (coefficient 0.045): much smaller contribution from
  the second angle, centred at $-1.10$ rad — likely a numerical artefact.
- **Constant offset $-3.67$**: sets the operating point of the softplus.

The mult node's contribution is visible in the **linear approximation**:

$$s^{(\text{KAN4})}_{\text{linear}} \;\approx\;
6.59\,l_0 + 12.05\,l_1 + 6.31\,l_2 + 7.33\,l_3
+ 0.21\,\theta_0 + 0.45\,\theta_1 - 0.25\,\theta_2$$
$$- 0.43\,\underbrace{(-1.38\,l_0 + 1.70\,l_2 + \dots)}_{A}
\cdot\underbrace{(2.67\,l_1 + 1.13\,l_2 + \dots)}_{B} - 3.99$$

All four chord lengths contribute with roughly equal positive coefficients (6–12),
and the bilinear correction $A \cdot B$ slightly reduces the score when adjacent
chord lengths differ strongly (a large-$l$ window preceded/followed by a small-$l$
window). The turning angles have coefficients an order of magnitude smaller than
the chord lengths — the mult node failed to amplify the curvature signal.

### 3.2 Second run — near-constant (outputs-2)

$$s^{(\text{KAN4})}_{\text{sparse}} \;\approx\;
0.0037\,(\theta_0 + 1.10)^2 - 0.0078\,(\theta_1 + 1.10)^2 + 0.027\,(\theta_2 + 0.69)^2$$
$$+ 0.157\left(0.232\,(\theta_0 + 1.10)^2 + 0.041\,(\theta_1 + 1.10)^2 + 1 + \frac{0.183}{(1 - 0.32\,l_2)^2} + \cdots\right)^{\!2} - 3.82$$

On real data the parenthesised expression evaluates to $\approx 1$ (since all
quadratic terms are small), so the whole formula collapses to $\approx 0.157 \cdot 1^2 - 3.82 \approx -3.66$
— effectively constant, with loss 0.018383.

## 4. KAN5 — Sliding Window, Soft-Quantile + Stage 2 Rebalancer

**Architecture:** `[3, 3+1, 1]` KAN with one mult node, window $w = 3$.  
**Inputs:** $[l_0,\; l_1,\; \lvert\theta_0\rvert]$ (3 features — absolute angle from outputs-2+).

### 4.1 Baseline with aux losses removed — meaningful formula (outputs-1)

The only KAN5 run that produced a consistently non-constant sparse formula,
and with a clear geometric interpretation:

$$\boxed{s^{(\text{KAN5})}_{\text{outputs-1}} \;\approx\;
7.53\,l_0 + 21.46\,l_1 - 3.41}$$

*(θ_0 is signed here — before the abs() fix — and cancels out.)*

**Interpretation:** Both chord lengths contribute positively. Longer chords on
either side of the vertex → higher density. The right-chord coefficient is nearly
3× the left-chord coefficient, suggesting the network learned an asymmetric
predictor that looks ahead more than behind — consistent with causal dependence
in the sliding window. The angle plays no measurable role; the network learned
a pure chord-length equidistribution, which is the **centripetal parameterisation**
rule.

The full bilinear (linear approximation, which captures the mult node):

$$s^{(\text{KAN5})}_{\text{linear}} =
7.53\,l_0 + 21.47\,l_1 + 0.15\,\theta_0
- 0.64\underbrace{(-2.42\,l_0 - 0.96\,l_1 + 0.18\,\theta_0 + 1.52)}_{A}
\cdot\underbrace{(0.62\,l_0 - 0.84\,l_1 - 0.47\,\theta_0 - 0.015)}_{B}
- 3.44$$

Factor $B \approx 0.62\,l_0 - 0.84\,l_1 - 0.47\,\theta_0$: this is approximately
the **chord-length asymmetry** $(l_0 - l_1)$ mixed with the angle. Factor $A$
contains an offset (~1.52) that makes $A \approx 1.5$ on average.
The correction $-0.64 \cdot A \cdot B$ therefore roughly subtracts
$-0.64 \cdot 1.5 \cdot B \approx -0.96 \cdot B$, i.e.
$+0.60\,l_1 - 0.45\,l_0 + 0.45\,\theta_0$. This slightly re-weights $l_0$ vs $l_1$
and introduces a small positive $\theta_0$ dependence through the mult node,
moving in the direction of the curvature formula.

### 4.2 With |θ₀| fix — constant (outputs-2,4,5,6)

From outputs-2 onward, $\lvert\theta_0\rvert$ is used. The sparse formula in all
subsequent runs collapses to a constant:

| Run | Sparse formula | Value |
|-----|---------------|-------|
| outputs-2 | constant | $-3.017$ |
| outputs-4 | constant | $-2.749$ |
| outputs-5 | constant | $-2.800$ |
| outputs-6 | constant | $-2.854$ |

Despite appearing trivial, the **linear approximation** of the best run (outputs-4)
reveals genuine bilinear structure:

$$s^{(\text{KAN5})}_{\text{linear, outputs-4}} \approx
64\,l_0 - 20\,l_1 + 1.8\,\lvert\theta_0\rvert$$
$$+ 38.6\,\underbrace{(-3.05\,l_0 + 1.85\,l_1 - 0.18\,\lvert\theta_0\rvert + 0.17)}_{A}
\cdot\underbrace{(-2.12\,l_0 + 1.28\,l_1 + 0.06\,\lvert\theta_0\rvert + 0.07)}_{B}
- 3.83$$

Both factors $A$ and $B$ are dominated by $l_0$ and $l_1$ with opposite signs,
so $A \cdot B \approx (−3.05\,l_0 + 1.85\,l_1)(−2.12\,l_0 + 1.28\,l_1)$
$= 6.47\,l_0^2 - 5.83\,l_0 l_1 + 2.37\,l_1^2$.
Multiplied by 38.6, the bilinear term contributes a quadratic that peaks when
$l_0 \approx l_1$. For typical smooth-curve windows this is almost always
satisfied, collapsing the formula to a near-constant. The variation due to
$\lvert\theta_0\rvert$ (coefficient 1.8 in the linear part, small in bilinear)
is below the softplus noise level.

### 4.3 Anomalous run with non-constant θ formula (outputs-3)

After NaN recovery, outputs-3 converged to a surprising purely-angular formula:

$$s^{(\text{KAN5})}_{\text{outputs-3}} \approx
-67.8\left(-\underbrace{(0.293\,\lvert\theta_0\rvert + 0.005)}_{{\approx\,0.293\lvert\theta_0\rvert}}
\underbrace{(0.272\,\lvert\theta_0\rvert - 0.638)}_{{}} + 0.232\right)^{\!2} + 0.0005$$

Expanding the inner bracket:
$$-0.080\,\theta_0^2 + 0.187\,\lvert\theta_0\rvert + 0.232$$

This peaks at $\lvert\theta_0\rvert \approx 1.2$ rad, giving a score
$\approx -67.8 \cdot (-0.080 \cdot 1.44 + 0.187 \cdot 1.2 + 0.232)^2 = -67.8 \cdot 0.278^2 \approx -5.2$.
For straight segments ($\theta_0 = 0$) the score is $-67.8 \cdot 0.232^2 \approx -3.65$.
So **high curvature → lower score → less density → fewer knots** — the **wrong
direction**. This inverted response explains why outputs-3 regressed to loss 0.0166.

## 5. Cross-Architecture Comparison

### 5.1 Summary table

| Model | Run | Formula type | Dominant terms | Angle sensitivity | Test loss |
|-------|-----|-------------|----------------|-------------------|-----------|
| KAN3 | outputs-2 | Complex nested (best run) | 7 features, exp/sin/cos | Signed, wrong sign | 0.011685 |
| KAN4 | outputs-1 | Quad in θ + linear l₀ | $l_0 + \theta_0^2$ | Approx via $\theta^2$ | 0.016466 |
| KAN5 | outputs-1 | Linear $l_0 + l_1$ | $l_0, l_1$ | None (signed θ cancels) | 0.014174 |
| KAN5 | outputs-3 | Quad in $\theta_0$ (inverted) | $\theta_0^2$ | Yes, but inverted | 0.016615 |
| KAN5 | outputs-4 | Bilinear (linear approx) | $l_0, l_1, \lvert\theta_0\rvert$ | Tiny | **0.008313** |

### 5.2 How close is each formula to the theoretical target?

The optimal score is $s^* \propto \lvert\theta\rvert^{1/4} \cdot (l_0 l_1)^{-1/4}$.

**KAN4 outputs-1** captures the $l_0$ dependence with correct direction (longer
chord → higher score). Using $\theta^2$ instead of $\lvert\theta\rvert^{1/4}$
gives the wrong functional form, but both increase monotonically with $|\theta|$
for small angles. The missing $1/l$ factor means the formula does not account
for scale: a high-curvature window with short chords (the case where knots matter
most) scores the same as a low-curvature window with long chords. Approximate match
with theory: **partial** (chord magnitude, direction correct; exponent wrong;
product $l_0 l_1$ absent; asymmetric in $l_k$).

**KAN5 outputs-1** (chord-length formula) corresponds to the **centripetal
parameterisation** heuristic: knot density ∝ $l$. This is a classical and
well-known good-enough rule, but it ignores curvature entirely. For curves with
nearly uniform chord lengths but highly variable curvature, it performs no better
than uniform knot placement. Approximate match with theory: **one factor only**
($l^{1/4}$ direction, wrong exponent).

**KAN5 outputs-4** (bilinear linear approximation) has both $l_0$ and $l_1$ with
opposite signs (64 vs −20), which approximates $l_0 - l_1$: chord-length asymmetry.
This is a **second-order** geometric quantity — a large positive $l_0 - l_1$ means
the left edge is longer than the right, i.e. the curve is decelerating. The small
$|\theta_0|$ coefficient (1.8) confirms curvature is barely felt. This is not the
right formula but the chord-asymmetry term is interesting — it detects inflection-like
regions where the parameterisation is changing speed, which are natural knot sites.
Approximate match with theory: **chord asymmetry proxy** (not the curvature formula).

## 6. What the Networks Learned (and Didn't Learn)

### Consistent findings across all runs

1. **Chord lengths are learned first and dominate.** Every non-constant formula
   assigns large positive coefficients to at least one chord length. This is the
   centripetal parameterisation heuristic, which the network discovers from data
   without being given it explicitly.

2. **Curvature ($\lvert\theta\rvert$) is systematically underweighted.** The angle
   contribution is always 1–3 orders of magnitude smaller than the chord-length
   contribution. This happens because smooth 2-D training curves have correlated
   chord lengths and turning angles: high curvature tends to occur in regions
   where chords are also shorter. The network can achieve low loss by learning
   the chord proxy alone, without needing to include the angle.

3. **The $l_0 \cdot l_1$ product (denominator of curvature) is never learned.**
   The theoretically optimal formula requires dividing by the chord product, not
   just adding chord lengths. The mult node in KAN4/5 has the capacity to represent
   this product, but converges instead to a bilinear correction that is nearly
   constant on the training distribution.

4. **The signed angle sign ambiguity breaks θ learning.** In runs before the
   $|\theta_0|$ fix (KAN3, KAN4, KAN5 outputs-0/1), the signed angle either
   cancels out (zero linear coefficient) or produces an asymmetric left-turn /
   right-turn response. The $|\theta_0|$ fix (outputs-2+) removes this ambiguity
   but does not by itself rescue the formula.

5. **NaN-recovery produces physically wrong formulas.** In outputs-3, gradient
   explosion followed by recovery trapped the network in an inverted-curvature
   attractor ($\theta^2$ with negative outer coefficient), correctly detected by
   higher test loss.

### Why the optimal formula was never reached

The optimal formula $\lvert\theta\rvert^{1/4} / (l_0 l_1)^{1/4}$ requires:
- A **ratio** (division, not product) of angle and chord lengths
- **Fractional exponents** (1/4 power)
- **Symmetry** in $l_0$ and $l_1$

The KAN with width `[3, 3+1, 1]` can represent products via the mult node, but
cannot represent divisions or fractional powers in a single forward pass without
explicit symbolic forcing. The training dynamics further prevent the network from
exploring this regime because the uniform-density fixed point (chord-length
heuristic) already achieves a loss of ~0.016, and the gradient of the soft-argmin
near that fixed point is nearly zero — there is no strong signal pushing the
formula towards $1/(l_0 l_1)$.

## 7. Numerical Quality Assessment

| Regime | Approximate test loss | Interpretation |
|--------|----------------------|---------------|
| Uniform knots (no learning) | ~0.040–0.060 | Worst case |
| Chord-length equidistribution | ~0.016 | Classical heuristic |
| Learned constant + Stage 2 offset | 0.008313 | KAN5 best |
| Learned chord-length formula | 0.014174 | KAN5 outputs-1 |
| KAN2 direct regression | 0.006773 | Best achieved |
| Ground truth (optimal knots) | 0 | Unachievable in practice |

The KAN5 Stage 1 formula (constant at best) achieves test loss 0.008 only because
Stage 2 applies a learned fixed offset $[\delta_1, \delta_2, \delta_3, \delta_4]$
on top of the uniform quantile baseline. This offset was found to be statistically
optimal on the training distribution — essentially a bias correction for the
systematic error of uniform knot placement on this particular dataset of 2-D curves.

A network that genuinely learned $s^* \propto \kappa^{1/4}$ would reduce the test
loss by an additional factor — estimated at 2–3× based on the gap between the
KAN2 result (0.0068) and the theoretical lower bound — but the gradient dynamics
of the current architecture make this unreachable.
