# KAN5 — Design Report

**Date:** 2026-05-20  
**Task:** Predict interior B-spline knot positions from a sampled point sequence
(Task 1, 2-D curves, degree 3, 6 knots, 100 points per curve).

---

## 1. Lineage and Motivation

### 1.1 What came before

| Model | Architecture | Trainable params | Best test loss |
|-------|-------------|-----------------|---------------|
| KAN2 | Direct: flattened 200-D curve → `[200,200,100,5]` KAN → softmax+cumsum | 726,000 | 0.006773 |
| KAN3 | Sliding window (w=5, 7 features) → `[7,16,16,1]` pure-addition KAN → Gaussian histogram → cumsum | 4,608 | 0.011685 |
| KAN4 | Sliding window (w=5, 7 features) → `[7,5+1,1]` mult-node KAN → density → CDF → soft-argmin | 660 | 0.016466 |
| **KAN5** | Sliding window (w=3, 3 features) → `[3,3+1,1]` KAN → density → CDF → soft-argmin + Stage 2 rebalancer | **1,162** | **0.008313** |

KAN3 and KAN4 explored whether a lightweight sliding-window approach could approach
KAN2's accuracy while using three orders of magnitude fewer parameters and
producing rotation-invariant, interpretable formulas.

**KAN3 result:** Histogram aggregation worked but the inverted semantics (high score
→ wide interval → fewer knots) and Gaussian-blur smoothing diluted the signal.
Best test loss: **0.011685**.

**KAN4 result:** Fixed the semantics (softplus→normalise→CDF→soft-argmin puts knots
where density is high), added a mult node to better approximate the curvature formula
$\kappa \propto |\theta| / (l_0 l_1)$, and replaced the histogram with a
differentiable soft-quantile. Despite cleaner gradients, the quantile approach
underperformed KAN3's histogram — best **0.016466** — because the soft-argmin
Jacobian near uniform density is nearly flat, giving Stage 1 almost no gradient
signal once it fell into the uniform fixed point.

**KAN5 goal:** Break through the ~0.011–0.016 wall by adding a **Stage 2
global rebalancer** that provides a per-curve correction on top of Stage 1's
coarse quantile estimate, and by training Stage 1 independently before Stage 2
is introduced.

## 2. KAN5 Architecture

### 2.1 Two-stage pipeline

```
Curve (100 pts, 2D)
       │
       ▼
 extract_windows()       → (B × N_w, 3)     [l_0, l_1, |θ_0|]  (w=3, stride=1)
       │
       ▼
 Stage 1 KAN_θ           → (B × N_w, 1)     raw score
  width [[3,0],[3,1],[1,0]],  k=3,  grid=5
       │
       ▼
 softplus(·) + ε         → (B, N_w)         density  (high = knot needed here)
 density / Σ density     → normalised probability distribution
       │
       ▼
 cumsum(density, dim=1)  → (B, N_w)         CDF over window positions τ
       │
       ▼
 softmax(-S|CDF-α_j|)    → (B, N_w, K)      soft-quantile weights  (S=25)
 Σ τ_i · w_{i,j}         → (B, K)           interior knots (K=4, α=[.2,.4,.6,.8])
       │
       ▼
 Stage 2 rebalancer KAN  → (B, K) delta     global correction
  width [[4,0],[8,0],[4,0]], k=3, grid=5
 knots ← sort(clamp(knots + δ_scale·tanh(delta)))
       │
       ▼
 Final knots (B, 6)      →  [0, k̂_1, k̂_2, k̂_3, k̂_4, 1]
```

### 2.2 Changes from KAN4

| Dimension | KAN4 | KAN5 |
|-----------|------|------|
| Window size | 5 (7 features) | 3 (3 features: `[l_0, l_1, \|θ_0\|]`) |
| Turning angle sign | Signed $\theta_0$ | Absolute value $\|\theta_0\|$ |
| KAN width | `[[7,0],[5,1],[1,0]]` | `[[3,0],[3,1],[1,0]]` |
| Grid intervals | 3 | 5 |
| Quantile sharpness | 15 | 25 |
| Stage 2 rebalancer | None | `[[4,0],[8,0],[4,0]]` KAN |
| Rebalancer output | — | $\delta_\text{scale} \cdot \tanh(\delta)$, clamped to $[10^{-3},\,1-10^{-3}]$ |
| Total trainable params | 660 | 1,162 |

**Absolute value on $\theta_0$:** The theoretically optimal weight is
$\kappa^{1/3}$ where $\kappa \propto |\theta_0|/(l_0 l_1)$. Using signed $\theta_0$
forces the KAN to learn the absolute value implicitly; using $|\theta_0|$
directly halves the symmetry the network must handle and sharpens learned formulas.

**Window size 3 instead of 5:** Fewer features (3 vs 7) while retaining all
information needed for local curvature estimation. The mult node computes $l_0
\cdot l_1$ exactly, after which $|\theta_0| / (l_0 l_1)$ is a simple ratio.

**Stage 2 rebalancer:** Takes the 4-dim quantile output from Stage 1 and applies
a learned global correction. The tanh bounds each per-knot delta to
$(-\delta_\text{scale},\; +\delta_\text{scale})$, preventing Stage 2 from
degenerate solutions (e.g., collapsing all knots to one location).

## 3. Training Procedure Changes from KAN4

### 3.1 Rebalancer warmup

The most impactful change. During the first `rebalancer_warmup` epochs Stage 2
is **frozen** (gradients disabled) and only Stage 1 trains. At epoch
`rebalancer_warmup` Stage 2 is unfrozen and its grid is recalibrated from Stage
1's current outputs. This forces Stage 1 to develop a useful density distribution
before Stage 2 can compensate.

Without warmup, Stage 2 co-adapts with Stage 1 from epoch 0 and immediately
learns to correct the uniform-density baseline, removing Stage 1's gradient
signal and trapping it in the constant fixed point. Warmup breaks this
dependency.

### 3.2 Beta freeze during warmup

`current_beta` (weight on the supervised knot-MSE loss) is held at its initial
value for the entire warmup phase and only begins decaying after Stage 2 is
unfrozen. This gives Stage 1 the full supervised signal during the frozen period.

### 3.3 Separate gradient clipping for Stage 2

After warmup, Stage 2 receives its own gradient-norm clip (`rebalancer_grad_clip
= 0.1`) applied before the global clip (0.5). Without a separate cap, Stage 1's
larger gradient norms dominate the global clip, allowing Stage 2 to take
unchecked large steps.

### 3.4 Auxiliary losses removed

| Loss term | KAN5 outputs-0 | From outputs-1 onward | Reason |
|-----------|---------------|----------------------|--------|
| Entropy $\lambda \sum d_i \log d_i$ | 0.01 | 0 | Penalises non-uniform density — the opposite of what Stage 1 should learn |
| Chord-length $\lambda\,\text{MSE}(\hat{k},\,k^\text{cl})$ | 0.1 | 0 | Reinforces the arc-length equidistribution fixed point, same basin as uniform density |

### 3.5 Density supervision (outputs-6 experiment)

Added a direct MSE loss between Stage 1's density output and a Gaussian target
centered on the true interior knots (sigma = half inter-knot spacing ≈ 0.10),
active only during warmup. Despite a well-formed gradient signal, this had no
measurable effect (see §4.6).

## 4. Run-by-Run Progression

### 4.1 Summary table

| Run | Key change(s) | Best test loss | Stage 1 formula |
|-----|---------------|---------------|-----------------|
| outputs-0 | Baseline (entropy λ=0.01, chord λ=0.1, S=15) | 0.016768 | constant ≈ −3.01 + tiny non-constant term |
| outputs-1 | Remove aux losses; rebalancer `[4→4→4]`, δ-scale=0.2 | 0.014174 | affine in $l_1, \|\theta_0\|$ + tiny correction |
| outputs-2 | $\|\theta_0\|$ abs; S=25; grid=5; rebalancer `[4→8→4]` | 0.011052 | constant ≈ −3.017 |
| outputs-3 | δ-scale=0.3; warmup=0; NaN instability resolved | 0.016615 | quadratic in $\|\theta_0\|$ (regression) |
| **outputs-4** | **warmup=100** | **0.008313** | constant ≈ −2.749 |
| outputs-5 | warmup=150; δ-scale=0.4; beta_min=0.25; beta frozen during warmup | 0.008546 | constant ≈ −2.800 |
| outputs-6 | density_lambda=1.0 (Gaussian target supervision) | 0.008324 | constant ≈ −2.854 |

**Best overall: outputs-4, test loss 0.008313.**

### 4.2 outputs-0: Baseline

First run with the two-stage architecture. Entropy and chord-length auxiliary
losses were inherited from earlier experiments. The entropy term
($\lambda \sum d_i \log d_i$) penalises concentrated density, actively discouraging
Stage 1 from placing density peaks at knot locations. The chord-length term
reinforces arc-length equidistribution, the same uniform basin Stage 1 needs to
escape. Both were removed in all subsequent runs.

### 4.3 outputs-1 and outputs-2: Baseline cleanup and |θ| fix

Removing aux losses reduced loss from 0.0168 → 0.0142. Switching to
$|\theta_0|$, increasing sharpness to 25, and widening the rebalancer to
`[4→8→4]` gave a further drop to 0.0111. These changes together confirm:
(a) the entropy and chord-length losses were actively harmful; (b) $|\theta_0|$
simplifies the learning problem.

### 4.4 outputs-3: Regression

An attempt to increase the rebalancer's correction budget (δ-scale 0.2→0.3)
without warmup produced a regression to 0.0166. Without warmup, Stage 2
immediately co-adapts and Stage 1 loses its training signal. NaN diagnostics
were added to the training loop during this run.

### 4.5 outputs-4: The warmup breakthrough

Setting `rebalancer_warmup = 100` dropped the test loss from ~0.011 to
**0.008313** — the single largest improvement in the entire experiment series.
The mechanism: with Stage 2 frozen for 100 epochs, Stage 1 receives the full
gradient from physics + supervised loss without Stage 2 absorbing the error.
At epoch 100 Stage 2's grid is calibrated from Stage 1's trained outputs, and
Stage 2 then learns only the residual correction.

### 4.6 outputs-5 and outputs-6: Plateau

Increasing warmup to 150 (outputs-5) and adding density supervision (outputs-6)
produced no improvement over outputs-4 (0.008546 and 0.008324 vs 0.008313).

**Density supervision null result.** Despite a valid gradient path from the MSE
loss to Stage 1's KAN parameters, Stage 1 still converged to a constant in all
three runs (outputs-4/5/6). The root cause is a near-zero Jacobian: at uniform
density the CDF is linear, and the soft-argmin Jacobian $\partial k_j / \partial
d_i$ is nearly zero for all $i$. The density supervision gradient
($\sim 1.6 \times 10^{-2}$) is insufficient to overcome the uniform-density
basin, which is further reinforced by the physics loss (uniform density gives
$[0.2, 0.4, 0.6, 0.8]$ knots — already a geometrically reasonable approximation
for many curves).

## 5. The Stage 1 Constant-Formula Finding

Across all seven runs, Stage 1's sparse formula was a constant after symbolic
regression:

| Run | Sparse formula | Constant value |
|-----|---------------|---------------|
| outputs-0 | constant + negligible non-constant | ≈ −3.01 |
| outputs-1 | affine in $l_1, \theta_0$ | non-constant |
| outputs-2 | constant | ≈ −3.02 |
| outputs-3 | quadratic in $\theta_0$ (anomaly — NaN recovery) | non-constant |
| outputs-4 | constant | ≈ −2.75 |
| outputs-5 | constant | ≈ −2.80 |
| outputs-6 | constant | ≈ −2.85 |

A constant Stage 1 score means density is identically uniform ($1/N_w$ everywhere),
which means Stage 1 always outputs $[0.2, 0.4, 0.6, 0.8]$ regardless of the input
curve. Stage 2 then learns a single fixed correction vector applied to every curve
equally — it is not per-curve adaptive. The model is effectively:

$$\hat{k} = [0.2,\; 0.4,\; 0.6,\; 0.8] + [\delta_1,\; \delta_2,\; \delta_3,\; \delta_4]$$

where $[\delta_1, \delta_2, \delta_3, \delta_4]$ is a learned constant offset.

The 0.008 floor is the best achievable test loss for this degenerate mode.

### 5.1 Why the spline plots look rich despite the constant formula

Inspecting the model figures (`figures/sp_l_i_j.png`) reveals apparently non-trivial,
non-flat activation curves for every edge — including both the layer-0 splines
(inputs $l_0, l_1, |\theta_0|$ → hidden nodes) and the layer-1 splines (hidden nodes
→ output). The constant symbolic formula is **not** a sign that the splines are
zeroed out. Three effects combine to produce this apparent contradiction.

**Effect 1 — matplotlib auto-scales every subplot.**
`save_spline_plots` renders each spline with `ax.axis("off")` and no explicit
`ylim`, so matplotlib stretches the y-axis to fill the figure regardless of the
actual value range. A function whose output spans $[-2.748,\,-2.752]$ (amplitude
0.004) looks visually identical to one spanning $[0,\,10]$. The rich shapes are
real learned curves; their actual amplitude is invisible in the plots.

**Effect 2 — `auto_symbolic` fits the output distribution, not the function shape.**
`formula_sparse.txt` is produced by pykan's `auto_symbolic`, which fits each
spline edge with the best candidate from the symbol library using $R^2$ on the
actual activation data. When the output variation on the training distribution is
small, $R^2$ for the constant candidate beats $R^2$ for `x`, `x²`, etc. — the
symbolic regression correctly reports "constant" because the signal is below its
discrimination threshold. This is accurate, not a bug.

**Effect 3 — the learned function is genuinely bilinear but evaluates to a narrow
range on real data.**
`formula_linear.txt` (produced by fitting each edge with an affine function and
composing) reveals the true underlying structure:

$$\text{score} = 63.9\,l_0 - 20.2\,l_1 + 1.78\,|\theta_0|
+ 38.6\underbrace{(-3.05\,l_0 + 1.85\,l_1 - 0.18\,|\theta_0| + 0.17)}_{\text{factor A}}
\underbrace{(-2.12\,l_0 + 1.28\,l_1 + 0.06\,|\theta_0| + 0.07)}_{\text{factor B}}
- 3.83$$

The mult node is active and encodes a product of two linear curvature proxies —
the right qualitative structure. However, on scale-normalised 2-D window features
from smooth curves ($l_0, l_1 \approx 0.02$, $|\theta_0|$ mostly small), the
large coefficients multiply inputs that are an order of magnitude smaller,
and the result lands near $-2.75$ for almost all windows. The variation
$\Delta\text{score} \approx \pm 0.1$–$0.2$ is real but small.

**The softplus kills the remaining variation.**
After applying softplus (and the fact that $\text{softplus}(x) \approx e^x$ for
$x \ll 0$), scores in $[-2.95,\,-2.55]$ produce density weights in
$[e^{-2.95},\,e^{-2.55}] \approx [0.052,\,0.078]$ — a ratio of about 1.5:1.
After normalising over 98 windows the density is nearly uniform; the CDF is
nearly linear; and soft-argmin of a linear CDF returns the fixed quantile
positions $[0.2,\,0.4,\,0.6,\,0.8]$.

In summary: **the splines are not trivial, but the network converged to a regime
where the bilinear composition produces scores in the negative-saturation zone of
softplus, making all density weights nearly equal regardless of which window is
being scored.**

## 7. Architectural Ceiling Analysis

### 7.1 Why the ceiling is at ~0.008

The CDF→soft-argmin aggregation is a **many-to-one bottleneck**: 98 window scores
are compressed to 4 scalar quantile positions. When Stage 1 is constant,
all information is destroyed and Stage 2 operates on the fixed vector
$[0.2, 0.4, 0.6, 0.8]$ for every curve. Adding more parameters, longer training,
or stronger supervision cannot compensate for zero per-curve information.

The uniform-density fixed point is a stable attractor because:
1. The physics loss at $[0.2, 0.4, 0.6, 0.8]$ knots is already low for typical
   curves (centripetal parameterisation gives roughly uniform chord lengths).
2. The Jacobian $\partial k_j / \partial d_i$ near uniform density is nearly zero
   — Stage 1 gradients are tiny regardless of loss.
3. Stage 2 co-adaptation, even with warmup, is fast enough to remove Stage 1's
   error signal before Stage 1 can escape the basin.

### 7.2 What would break the ceiling

To substantially improve below 0.008 within a sliding-window framework:

| Approach | Mechanism | Risk |
|----------|-----------|------|
| **Directly regress** 4 knots from per-window features (skip the density/CDF path) | Removes the zero-Jacobian bottleneck; gives Stage 1 a direct gradient | Loses monotonicity guarantee; may need separate sorting |
| **Wider window** with richer local context (e.g., curvature, torsion) | More discriminative features → non-constant Stage 1 | Larger input dim; still hits CDF bottleneck |
| **Feed 98-dim density to Stage 2** instead of 4-dim quantile output | Stage 2 gets full per-curve information | Stage 2 becomes much larger; harder to train |
| **Abandon sliding-window** (back to KAN2-style) but with invariant preprocessing | Trades interpretability for accuracy; KAN2 shows 0.007 is achievable | High param count, uninterpretable formulas |

### 7.3 Conclusion

KAN5 successfully demonstrates that a **1,162-parameter** two-stage model can
achieve 0.008 test loss on 2-D B-spline knot prediction — halving the error of
the KAN4/KAN3 baselines, reaching within 23% of KAN2's 726k-parameter result.
The rebalancer warmup is the decisive mechanism (single run improvement:
0.011 → 0.008).

The remaining gap to KAN2 is structural: Stage 1 invariably collapses to a
constant density, making the model equivalent to a learned global offset from
arc-length equidistribution. Closing this gap requires either different
aggregation (direct 4-knot regression) or abandoning the sliding-window
paradigm.
